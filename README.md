# Elegance Wheels

An AI-powered smart car showroom website where visitors can discover their dream car.

**Live site:** https://smart-auto-showroom.vercel.app/

## Overview

Elegance Wheels is a web application for a luxury automotive showroom. It gives buyers a modern, easy way to explore vehicles online and find the car that suits them, replacing static listings and phone-call enquiries with an interactive experience.
